## 🇪🇸 Español

### 📌 Descripción

Proyecto personal desarrollado con **React.js y Vite** que presenta una colección de cinco tarjetas dedicadas a la gastronomía peruana.

La aplicación incluye tres platos principales, un desayuno y un postre tradicional del Perú, mediante una interfaz visual y adaptable a diferentes dispositivos.

### 🍽️ Características

- Diseño responsive.
- Cinco tarjetas dedicadas a la gastronomía peruana.
- Componentes reutilizables desarrollados con React.
- Organización modular de los componentes.
- Presentación de platos mediante imágenes y descripciones.

### 🛠️ Tecnologías utilizadas

- React.js
- Vite
- JavaScript
- HTML5
- CSS3

### 🚀 Instalación y ejecución

1. Clonar el repositorio:

   ```bash
   git clone URL_DEL_REPOSITORIO
   ```

2. Acceder al proyecto:

   ```bash
   cd cards-react
   ```

3. Instalar las dependencias:

   ```bash
   npm install
   ```

4. Ejecutar el proyecto:

   ```bash
   npm run dev
   ```

## 🇬🇧 English

### 📌 About the Project

Personal project developed with **React.js and Vite**, featuring a collection of five cards dedicated to Peruvian gastronomy.

The application includes three main dishes, one breakfast and one traditional Peruvian dessert, presented through a responsive interface.

### 🍽️ Features

- Responsive design.
- Five cards showcasing Peruvian gastronomy.
- Reusable components developed with React.
- Modular component structure.
- Food presentation through images and descriptions.

### 🛠️ Technologies Used

- React.js
- Vite
- JavaScript
- HTML5
- CSS3

### 🚀 Installation and Setup

1. Clone the repository:

   ```bash
   git clone REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd cards-react
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
